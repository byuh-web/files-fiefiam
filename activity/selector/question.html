What is the difference between an ID and a Class?

An ID is unique and can only be used on a single HTML element per page, while a Class can be reused on multiple elements across the page, which is perfect for applying the same styling or behavior to a group of items

What is the difference between a SPAN tag and a DIV tag?

SPAN is used inside a line or inline coding while on the other hand DIV uses a block of code. DIV starts in a new line while SPAN doesn't.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A DIV is a non-semantic generic container. a HEADER, MAIN, FOOTER are semantic
